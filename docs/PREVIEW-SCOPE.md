## Implemented

Eight learning units, 32 core lessons, 97 authored exercises, 24 builder challenges, six main games, independent practice, original artwork, English/Thai word help and local save/recovery. Lunch Lens, CampusCompass and StudyBuddy have independent saved drafts and Build / Try / Notes views.

Core learning is free after sign-in. Pro access depends on a current authenticated RevenueCat entitlement; it adds helpers, eight bonus labs, unlimited shop Sparks and full Project Pack export/copying. These rules do not provide cloud backup, unlimited projects or a higher AI quota.

Google sign-in was exercised on web and Android. Authenticated live Ami and Noa web replies were recorded on 1 October. Provider usage remained zero at the before/after check with a dedicated zero-dollar-cap key. This is dated response/cost evidence, not a promise that a free model will always remain available. An earlier compatible native build completed a RevenueCat Test Store monthly purchase and restore, matched to provider-side sandbox evidence. The observed test entitlement later expired. Full owned Project Pack export was not executed. No sandbox result establishes real revenue or production Google Play billing.

## Service and data boundaries

Gameplay requires a valid Supabase session. Email signup/confirmation may be constrained by development email delivery. Authored practice needs no model key after sign-in. Missing online service configuration is displayed honestly.

The prototypes use authored/simulated data inside ShipingIT. CampusCompass has no live GPS/navigation integration. StudyBuddy's live AI is off. Live Ami/character requests go through an authenticated server adapter; authored fallback advice is labeled separately and never controls grades or rewards.

Progress, notebooks and prototype drafts stay on the device. Signing in does not sync or back them up. Export important work before resetting or uninstalling. Broad native acceptance, measured startup improvements, every installed voice's quality and a production store launch remain outside this preview's verified scope.
